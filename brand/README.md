# CHIUDI — Kit di marca v1

Questa cartella contiene la fonte tecnica del sistema di marca CHIUDI.

Tutto il materiale visibile all’utente è prodotto in italiano.

- `manuale-marca.md` — regole canoniche;
- `token/` — colori, spaziature, raggi e tipografia;
- `loghi/` — marchio vettoriale e monogramma;
- `modelli/` — composizioni di base;
- `guide/` — istruzioni per Figma e Canva.

La cartella Drive `CHIUDI` contiene inoltre PNG pronti all’uso e l’esportazione ZIP completa.
